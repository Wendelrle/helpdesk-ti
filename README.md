# HelpDesk TI

## Sobre o projeto

O HelpDesk TI é um sistema desenvolvido para facilitar o registro e gerenciamento de chamados de suporte técnico.

O projeto foi desenvolvido como atividade acadêmica do curso de Análise e Desenvolvimento de Sistemas.

## Funcionalidades

- Cadastro de usuários
- Login de usuários
- Abertura de chamados
- Definição de categoria do chamado
- Definição de prioridade

## Tecnologia utilizada

### Front-end
- HTML
- CSS
- JavaScript

### Back-end
- Python
- FastAPI

### Banco de Dados
- PostgreSQL

## Estrutura do projeto

- `front-end/` - Interface do sistema
- `backend/` - API e regras do sistema
- `.gitignore` - Arquivos e pastas ignorados pelo Git

## Objetivo

O objetivo do projeto é aplicar na prática conceitos de desenvolvimento de sistemas, utilizando front-end, back-end e banco de dados em uma aplicação de três camadas.
